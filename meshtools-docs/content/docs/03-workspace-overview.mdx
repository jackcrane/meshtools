---
title: Workspace Overview
description: Learn what each pane in the MeshTools editor is for.
---

MeshTools is organized around three working areas.

## Left Pane

The left pane combines three jobs:

- `Scene`: shows the active document and every entity set in the project.
- `History`: gives you undo, redo, a rollback slider for the active branch, and a history tree.
- `Inspector`: shows document metadata such as source path, format, counts, bounds, and project up axis.

Double-click an entity set name in the scene tree to rename it.

## Viewport

The center viewport is where you:

- view the rendered mesh,
- orbit, pan, and zoom the camera,
- select faces, edges, and points,
- open right-click tools,
- preview advanced selection operations, and
- run geometry edits.

The viewport also has two overlay control stacks:

- display controls for wireframe, shaded triangles, and point display,
- selection filters for edges, faces, and points.

## Bottom Pane

The bottom pane has three tabs:

| Tab | Purpose |
| --- | --- |
| `Console` | Chronological activity log |
| `Stats` | frame time, FPS, display size, and optional task timings |
| `Selection` | counts and IDs for the active mesh selection |

The selection tab is especially useful when you need to verify exact face, edge, or point IDs before running a tool.

## Settings Window

Open `Settings` from the app menu to configure:

- viewport controls,
- graphics quality,
- file import defaults,
- appearance and themes.
